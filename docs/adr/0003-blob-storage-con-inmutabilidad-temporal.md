# ADR-03 · Blob Storage con inmutabilidad temporal

- **Estado:** aceptada (SPEC §1)

## Contexto
Custodia de recetas 5 años con integridad demostrable.

## Decisión
Contenedor `recetas` con política de inmutabilidad temporal (5 años) y ciclo de vida Hot→Cool→Cold; contenedor `reportes`.
