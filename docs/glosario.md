# Glosario

Términos del dominio regulatorio que se mantienen en español en el código y su equivalente técnico.

| Término                                     | Significado                                                                                                                                                                                                          | En el código                                                |
| ------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------- |
| Receta                                      | Prescripción veterinaria (papel o electrónica, RD 666/2023)                                                                                                                                                          | `receta`, `RecetaConfirmada`                                |
| Nº de registro (`nregistro`)                | Identificador del medicamento en CIMAVet (p. ej. `1868 ESP`)                                                                                                                                                         | `nregistro`                                                 |
| Código nacional (CN)                        | Identificador de 6 dígitos de la presentación (7 con dígito de control). En la UI: "Código nacional"                                                                                                                 | `cn`                                                        |
| Presentación                                | Formato concreto de un medicamento (envase, contenido)                                                                                                                                                               | `PresentacionInfo`                                          |
| Principio activo (PA)                       | Sustancia activa; `pa_id` de la maestra de CIMAVet                                                                                                                                                                   | `paId`                                                      |
| Garante                                     | Farmacéutico garante del establecimiento. No usa la app: su autorización previa y su firma las registra el empleado; revisa el reporte semanal                                                                       | —                                                           |
| Dispensación                                | Entrega de un medicamento; registro de salida append-only                                                                                                                                                            | `dispensacion`                                              |
| Entrada / recepción                         | Recepción de mercancía de un distribuidor                                                                                                                                                                            | `recepcion`, `recepcion_linea`                              |
| Albarán                                     | Documento del proveedor que acompaña a la mercancía (o factura); se puede leer con Document Intelligence para proponer las líneas                                                                                    | `LecturaAlbaran`, `albaranDesdeFactura`                     |
| Importación                                 | Lote de entradas o salidas anteriores a la app cargado de un Excel/CSV; se anula, nunca se modifica                                                                                                                  | `importacion`, `entrada_importada`, `salida_importada`      |
| Fecha de recepción                          | Día en que llega la mercancía; puede ser posterior a la fecha de compra del albarán                                                                                                                                  | `fechaRecepcion`                                            |
| Entrada caducada                            | Línea de entrada con caducidad anterior a hoy: no se puede registrar                                                                                                                                                 | `entradaCaducada`, `ENTRADA_CADUCADA`                       |
| Recargo de equivalencia (RE)                | Recargo del IVA que se suma al precio neto de compra para el coste; el precio neto se introduce sin IVA ni RE                                                                                                        | `rePct`, `calcularPrecioCoste`                              |
| Forzado                                     | Dispensar pese a un defecto de forma, asumiendo la responsabilidad (SPEC §4.1.6)                                                                                                                                     | `forzado`, `validarForzado`                                 |
| Defecto de forma                            | Incidencia `BLOQUEANTE_FORMA`: no se puede dispensar, pero se puede forzar                                                                                                                                           | `BLOQUEANTE_FORMA`                                          |
| Bloqueo duro                                | Incidencia `BLOQUEANTE_DURO`: no se puede dispensar ni forzar                                                                                                                                                        | `BLOQUEANTE_DURO`                                           |
| Aviso                                       | Incidencia informativa                                                                                                                                                                                               | `AVISO`                                                     |
| Sustitución                                 | Dispensar un medicamento equivalente al prescrito (SPEC §4.4)                                                                                                                                                        | `sustitucion`                                               |
| Cambio de formato / concentración           | Otra presentación del mismo principio activo (SPEC §4.3.1)                                                                                                                                                           | `DISPENSAR_CON_AVISO`                                       |
| FEFO                                        | _First expired, first out_: primero el lote que caduca antes                                                                                                                                                         | `proponerLotes`                                             |
| Tiempo de espera                            | Plazo hasta que la carne, leche, huevos… de un animal tratado pueden consumirse                                                                                                                                      | `tiemposEspera`                                             |
| Especie productora                          | Animal productor de alimentos                                                                                                                                                                                        | `especieProduccion`                                         |
| REGA                                        | Registro General de Explotaciones Ganaderas                                                                                                                                                                          | `rega`                                                      |
| Talonario colegial                          | Recetario del colegio con numeración que incluye el nº de colegiado                                                                                                                                                  | `talonarioColegial`                                         |
| Psicótropo / estupefaciente                 | Medicamentos sujetos a control especial (CIMAVet)                                                                                                                                                                    | `psicotropo`, `estupefaciente`                              |
| Antimicrobiano                              | Antibiótico o ATC QJ01/QJ02/QJ04/QJ05/QP51                                                                                                                                                                           | `esAntimicrobiano`                                          |
| Recargo de equivalencia (RE)                | Recargo de IVA del comercio minorista                                                                                                                                                                                | `calcularPrecioCoste`                                       |
| Nomenclátor                                 | Fichero XML de la AEMPS con todos los medicamentos veterinarios                                                                                                                                                      | `importarNomenclator`                                       |
| CIMAVet                                     | Centro de Información de Medicamentos Veterinarios (AEMPS)                                                                                                                                                           | `packages/cimavet`                                          |
| Siweb360                                    | ERP/TPV con el inventario de la tienda                                                                                                                                                                               | `packages/siweb`                                            |
| TPV                                         | Terminal punto de venta (ticket); descuenta el stock al cobrar                                                                                                                                                       | —                                                           |
| Outbox                                      | Cola de escrituras en Siweb360 con reconciliación manual                                                                                                                                                             | `OutboxService`                                             |
| Contramovimiento                            | Corrección por fila nueva (nunca `UPDATE`)                                                                                                                                                                           | `anula_dispensacion_id`                                     |
| D-xx                                        | Decisión de SPEC §13; las pendientes llevan `TODO(decision D-xx)`                                                                                                                                                    | —                                                           |
| Asistente (de consultas)                    | Chat en español que explica las reglas y el resultado de una receta; solo informa, nunca decide ni autoriza (ADR-17)                                                                                                 | `@mmx/assistant`, `ChatOrchestrator`                        |
| Simulación                                  | Evaluación de un caso hipotético por el motor de reglas (por ejemplo, «receta del 3 de octubre con antibiótico»); no crea ni modifica ninguna receta                                                                 | `packages/domain/src/simulacion.ts`, `simular_*`            |
| Fuente de referencia                        | Documento o regla versionada que el asistente cita y se puede abrir: regla del motor (`regla:`), guía de la receta (`guia:`), Ayuda (`ayuda:`), medicamento de CIMAVet (`cimavet:`) o resultado del motor (`motor:`) | `FuenteCitada`                                              |
| Conciliación TPV                            | Emparejamiento entre las salidas de dispensación y los tickets de cobro del TPV (automático o asistido)                                                                                                              | `conciliarDia`, `buscarTickets`                             |
| Asociación manual de ticket                 | Vinculación explícita y auditada por el personal de un ticket de TPV a una salida cuando falta el CN o difiere la descripción                                                                                        | `asociarManual`, `origen: 'manual'`                         |
| Vinculación ticket-receta (`ticket_receta`) | Asociación explícita 1:N entre un ticket de venta del TPV y múltiples recetas; consolida la conciliación multi-receta con bloqueo por exceso dispensado (D-11)                                                       | `ticket_receta`, `conciliarTicketMultiReceta`               |
| Modo retrospectivo (formación)              | Modalidad de dispensación para formación del personal con transacciones del pasado; valida stock contra movimientos históricos (`sale_shipment`) en lugar de stock actual (D-14)                                     | `modo: 'retrospectivo'`, `evaluarMovimientosRetrospectivos` |
| Pricing de variantes                        | Sincronización de coste (`cost_cents`) y precio de venta de variantes con Siweb360 API 1.2.0                                                                                                                         | `actualizarPrecios`, `siweb_actualizar_precio`              |
| Alta manual de receta (`origen: 'manual'`)  | Receta registrada sin imagen por la veterinaria responsable, con la dispensación ya hecha en su fecha original; medicamento y especie se eligen de CIMAVet | `crearManual`, `MANUAL_PRESCRIPTION_ENTRY` |
| Custodia del papel (`custodiaPapel`)        | Dónde se guarda la receta en papel de un alta manual (sin datos personales)                                                                              | `receta.custodia_papel`                                     |
